# Схема содержания курса

Содержание лежит в `content/` и отдаётся оболочкой; оболочка читает только описанные
здесь файлы. Изменение этой схемы — только с согласия автора, через ADR.
Валидатор: `scripts/validate_content.py` (запускается PostToolUse-хуком автоматически).

## course.json
```json
{
  "title": "История ИИ в тематических срезах",
  "slices": [
    { "id": "ai-overview",  "title": "Что такое ИИ: карта курса" },
    { "id": "neuron-1943",  "title": "Нейрон Мак-Каллока и Питтса" }
  ]
}
```
Порядок элементов `slices` — и есть линейный порядок курса (полный порядок; DAG из
предыдущего проекта вырожден в последовательность; поле prerequisites не нужно:
предшественник — предыдущий элемент списка).

## slices/<slice-id>/slice.json
```json
{
  "id": "perceptron-1958",
  "title": "Однослойный персептрон Розенблатта",
  "yearFrom": 1957,
  "yearTo": 1969,
  "track": "genai",
  "period": "golden",
  "summary": "ЧЕРНОВИК: одна-две фразы, что вводит срез.",
  "pages": [
    { "id": "idea",     "type": "idea",         "file": "pages/01-idea.md" },
    { "id": "math",     "type": "math",         "file": "pages/02-math.md" },
    { "id": "demo-line","type": "demo",         "file": "pages/03-demo-line.md" },
    { "id": "quest",    "type": "questions",    "file": "pages/90-questions.md" },
    { "id": "assign",   "type": "assignments",  "file": "pages/91-assignments.md" }
  ],
  "status": "draft"
}
```
- `track`: `genai` | `xai`. `period`: `golden` | `winter`. Чередование периодов задаёт
  логику «надежды ↔ разочарования»; winter-срезы трека `xai` на стадии 0→1 — только
  обзорные.
- `status`: `draft` | `approved` — меняет только автор.

## Типология страниц (`pages[].type`)
| type            | что это |
|-----------------|---------|
| `overview`        | обзорная страница общего характера (введение в проблематику) |
| `winter-overview` | обзор winter-периода: куда смещались ожидания и почему |
| `idea`            | новая идея — предварительное неформальное описание |
| `math`            | математический аппарат идеи (матричная алгебра и далее) |
| `library`         | возможности NumPy/PyTorch применительно к текущему примеру |
| `code-example`    | пример сети с кодом реализации |
| `demo`            | то же + визуализация (проигрывание трассы в iframe) |
| `history`         | исторический экскурс, биографическая врезка |
| `summary`         | резюме среза |
| `questions`       | вопросы для самоконтроля с раскрываемыми ответами |
| `assignments`     | задания для самостоятельных экспериментов |

Файл страницы — Markdown с YAML front-matter (`title`, опционально `demo: <demo-id>`
для страниц типа `demo`). Тексты до утверждения автором начинаются с `ЧЕРНОВИК:`.

## slices/<slice-id>/demos/<demo-id>/demo.json
```json
{
  "id": "neuron-line",
  "title": "Один нейрон учится разделять точки прямой",
  "entry": "index.html",
  "trace": "trace.json",
  "gen": { "numpy": "gen/numpy/train.py", "torch": "gen/torch/train.py" }
}
```
`entry` открывается оболочкой в iframe; `gen` — скрипты генерации трассы (хотя бы один).

## Трасса (trace.json)
```json
{
  "meta": { "seed": 42, "lib": "numpy", "task": "...", "hyper": { "lr": 0.1, "epochs": 1 } },
  "points": [ { "x": 0.2, "y": 0.7, "cls": 1 } ],
  "steps":  [ { "i": 0, "params": { "k": 0.35, "b": -0.1 }, "loss": 0.42 } ]
}
```
- `points` — обучающие точки в порядке предъявления; `steps[j].i` — индекс точки,
  обработанной на шаге j; `params` — параметры модели после шага, достаточные для
  отрисовки разделяющих линий (для нейрона — k и b; для слоёв — массивы весов).
- Поведение плеера едино для всех демо: до старта все точки полупрозрачны; на шаге i
  точка i становится непрозрачной и линия перерисовывается; пуск/пауза/шаг/сброс/скорость.
- trace.json держать < 1 МБ: при длинных обучениях записывать каждый n-й шаг.

## questions.json
```json
[ { "id": "q1", "question": "ЧЕРНОВИК: ...", "answer": "ЧЕРНОВИК: полный ответ, раскрывается по клику" } ]
```
Не менее пяти вопросов на срез; без вариантов ответа (это самоконтроль, не экзамен).

## assignments.json
```json
[ { "id": "a1", "task": "ЧЕРНОВИК: что сделать", "demo": "neuron-line",
    "hints": ["..."], "expect": "ЧЕРНОВИК: что обучаемый должен увидеть" } ]
```
Задания привязаны к демо и к коду генераторов (меняй 1–2 строки — смотри на результат).
