# 0005. Генератор трассы на чистом Python и общий плеер демо
Дата: 2026-10-27. Статус: proposed (утверждает автор).

## Контекст
1. Brief (раздел 1, п. 3) задаёт сквозную линию «нейрон "в лоб" на чистом Python →
   матричная алгебра → NumPy → PyTorch». Схема содержания (content-schema.md) допускает
   в `demo.json.gen` только ключи `numpy` и `torch`, поэтому первый, самый простой код курса
   не может быть генератором трассы — а значит, не может быть и «кодом для показа»
   на странице демо (ADR 0002: показываемый код = исполняемый код).
2. Скилл `new-demo` предполагает один общий `player.js` на все демо. ADR 0004 разрешает
   демо ссылаться только на файлы своей папки `demos/<id>/`, то есть плеер пришлось бы
   копировать в каждое демо, и копии со временем разойдутся.

## Решение
1. В `demo.json.gen` добавляется третий допустимый ключ `python` — генератор без
   библиотек (только стандартная библиотека Python). Требование одинаковой трассы
   распространяется на все реализации одного демо: `python`, `numpy`, `torch` при одном
   seed дают одну трассу (с точностью до float-погрешности).
2. Общие файлы демо (плеер и его стили) лежат в `content/_shared/player/`.
   Оболочка отдаёт их маршрутом `GET /content/_shared/{path}` — без проверки состояния
   среза, потому что это не содержание какого-либо среза, а инструмент показа.
   Внутри `_shared/` — только плеер и его ресурсы; тексты, трассы, страницы — никогда.
   Демо подключает плеер по пути `/content/_shared/player/player.js`; функция отрисовки
   модели остаётся в папке демо.
3. `_shared` не является срезом: `course.json` его не упоминает, валидатор и загрузчик
   содержания его пропускают.

## Последствия (включая то, что стало труднее)
+ Первый код курса — нейрон на чистом Python — сразу становится и генератором трассы,
  и кодом на странице; переход к NumPy показывается на той же трассе.
+ Плеер один; исправление в нём сразу действует во всех демо.
− Изменение плеера может сломать старые демо: нужен тест, который открывает каждое демо
  и проверяет, что его трасса читается плеером (хотя бы на уровне формата trace.json).
− Схема содержания и валидатор меняются (gen.python, `_shared/`); ADR 0004 дополняется
  исключением для `_shared/`.

## Альтернативы, которые отвергнуты, и почему
Чистый Python только как текст на странице, без трассы — отвергнуто: нарушает принцип
«показываемый код исполняется» (ADR 0002) и прячет главную мысль страницы — что NumPy
даёт тот же результат.
Плеер как часть оболочки (`app/static/`) — отвергнуто: оболочка не должна знать
устройство плеера (ADR 0001).
Копия плеера в каждом демо + тест на совпадение копий — работоспособно, но хуже:
дублирование ради формального соблюдения правила.
