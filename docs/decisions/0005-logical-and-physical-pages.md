# 0005. Логическая страница из нескольких физических; закреплённый рисунок
Дата: 2026-10-27. Статус: proposed (утверждает автор).

## Контекст
Страница 11 «О чём этот курс» (11.v1) получилась длинной: семь разделов и два рисунка.
Автор решил (11.v1-to-2.prompt) тематическое деление не менять, а длинную логическую
страницу показывать как несколько физических веб-страниц, где меняется только часть
экрана, а рисунок 1 (соотношение пяти областей) закреплён. Сейчас в схеме содержания
два уровня: срез → страницы (`slice.json.pages`), страница = один Markdown-файл.

## Решение (предлагается)
- `slice.json.pages` по-прежнему перечисляет **физические** страницы в порядке показа.
- Новое необязательное поле `group` — id логической страницы: физические страницы
  с одинаковым `group` идут подряд и в оглавлении показываются одним пунктом
  с подпунктами.
- Новое необязательное поле `pinned` — путь к рисунку внутри среза
  (`figures/<file>.png`); оболочка показывает его закреплённым рядом с текстом
  (на узком экране — над текстом) на всех физических страницах, где поле задано.
- Пример для страницы 11: `about-intro` (введение + рисунок 1 в тексте), `about-ai`,
  `about-ml`, `about-nn`, `about-dl`, `about-genai` (рисунок 1 закреплён),
  `about-timeline` (рисунок 2 в тексте, без закрепления), `about-structure`.
- Рисунки среза — в `content/slices/<slice-id>/figures/`; оболочка отдаёт их только для
  доступного среза, как демо (ADR 0004).

## Последствия (включая то, что стало труднее)
+ Длинная логическая страница читается частями, опорный рисунок всегда перед глазами.
+ Совместимо с текущим содержанием: без `group` и `pinned` всё работает как раньше.
− Изменяются схема содержания, валидатор, шаблон страницы и маршрут статики (рисунки).
− «Срез пройден» по-прежнему на последней физической странице среза — логическая
  страница отдельного состояния в БД не получает (схема БД не меняется).

## Альтернативы, которые отвергнуты, и почему
- Одна длинная физическая страница — отвергнуто автором (объём).
- Разнести разделы по разным логическим страницам (01-overview, 02-history) — автор
  решил тематическое деление оставить.
- Закреплять оба рисунка — рисунок 2 (хронология) нужен только в разделе 6;
  закреплённым он занимал бы место без пользы. Можно вернуться к этому по решению автора.
