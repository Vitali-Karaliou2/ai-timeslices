## Задача
1. **Новый черновой срез `perceptron-1958`** (по скиллу `new-slice`) — «Персептрон
   Розенблатта», трек `genai`, период `golden`; в `course.json` — сразу после
   `neuron-1943`. Годы — `ПРОВЕРИТЬ ДАТУ: 1957–1969` (отчёт Розенблатта 1957,
   статья в Psychological Review 1958; верхняя граница — книга Минского и Пейперта
   «Perceptrons», 1969). Демо обучения ставится сюда, а не в `neuron-1943`:
   модель Мак-Каллока–Питтса весов не обучала.
   Страницы (тексты — с пометкой `ЧЕРНОВИК:`): `idea` → `math` → `code-example`
   → `demo` → `summary` → `questions`. Всё про библиотеки — пока внутри code-example.
2. **Демо `neuron-line`** (по скиллу `new-demo`).
   - Задача: точки двух классов на плоскости над и под прямой. Модель — по постановке
     автора: «нейрон с входами x и 1, веса k и b». На странице `math` объясни,
     что для классификации точки (x, y) сравнивается y с kx + b, то есть нейрон
     вычисляет sign(y − (kx + b)): это нейрон со входами (x, y, 1), у которого вес при y
     зафиксирован равным 1. Именно поэтому параметров два и матрица весов 2×1.
     Правило обучения — правило персептрона для k и b (выведи его на странице `math`
     явно, по шагам).
   - Генераторы трассы: вариант А — `gen/python/train.py` (без библиотек, «в лоб»)
     и `gen/numpy/train.py`; вариант Б — только `gen/numpy/train.py`, а чистый Python
     дай на странице `code-example` как текст и пометь в отчёте, что он не исполняется.
     Seed фиксирован. Число точек — 40–60. Должны получиться небольшие, но видимые
     промахи у прямой в начале обучения.
   - Если реализаций две, добавь тест: обе дают одну трассу (сравнение с допуском
     1e-9). Также добавь тест, что `trace.json` в репозитории совпадает с выводом
     генератора, то есть трасса не устарела.
   - Плеер: canvas, без библиотек; пуск / пауза / шаг / сброс / скорость. До старта
     все точки полупрозрачные, на шаге i точка i становится непрозрачной, прямая
     перерисовывается по k и b. Вариант А — общий плеер в `content/_shared/player/`
     (маршрут оболочки по ADR 0005, тест на него); вариант Б — плеер в папке демо.
3. **Оболочка: страница `type: demo`.** Front-matter `demo: <demo-id>` → iframe
   на `entry` и рядом код генератора. Если генераторов несколько — переключатель
   python / numpy (выбор запоминается в URL, без JS-фреймворков). Тесты:
   страница демо отдаёт 200 и содержит iframe; файлы демо недоступного среза → 403.
4. **Страница `type: questions`.** Вопросы из `questions.json` с раскрываемыми
   ответами (`<details>`). Для `perceptron-1958` — не меньше пяти вопросов (`ЧЕРНОВИК:`).
5. **Мелочи из отчёта сессии 01:**
   - гонка при одновременных первых запросах (500) — get-or-create с перехватом
     IntegrityError и повтором; тест — по возможности;
   - предупреждение про httpx2 в тестах — не трогать.
6. `pytest` зелёный. Субагенты `code-reviewer` и `fact-reviewer` (на срез
   `perceptron-1958`). Если после ревью были блокирующие исправления — запусти
   `code-reviewer` ещё раз. Коммит, пуш, PR, отчёт по скиллу `session-report`.
