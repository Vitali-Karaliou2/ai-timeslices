# Шаблон промпта сессии (для Claude Code, сессии с GitHub)

Нумерация сессий этого проекта — своя: `01_ИИ`, `02_ИИ`, … Чтобы она была видна везде,
она повторяется в трёх местах: в первой строке промпта, в имени ветки
(`session-NN-ai-<тема>`) и в имени файла плана (`docs/plans/session-NN-<тема>.md`).
Список сессий в интерфейсе Claude Code не группируется по проектам, поэтому первая
строка промпта — единственный надёжный способ отличать сессии двух проектов;
при желании сессию можно переименовать в интерфейсе по этой же строке.

## Шаблон
```
Сессия NN_ИИ, проект ai-timeslices.
Прочитай CLAUDE.md, docs/plans/session-NN-<тема>.md и новые файлы в docs/decisions/.
Работай в ветке session-NN-ai-<тема>. Выполни задачу сессии.
Перед PR — субагент code-reviewer (и fact-reviewer, если менялись тексты срезов).
Заверши отчётом по скиллу session-report и создай PR.
Дополнительно в этой сессии: <ссылки на новые ADR/документы или «ничего»>.
```

## Промпт сессии 01_ИИ (дословно)
```
Сессия 01_ИИ, проект ai-timeslices.
Прочитай CLAUDE.md, docs/plans/session-01-skeleton.md и docs/decisions/.
Работай в ветке session-01-ai-skeleton. Выполни задачу сессии.
Перед PR — субагент code-reviewer.
Заверши отчётом по скиллу session-report и создай PR.
Дополнительно в этой сессии: ничего.
```
