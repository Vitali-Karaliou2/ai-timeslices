# Решения, откладываемые на будущее

Автор иногда отвечает на вопрос «решим позже, напомни, когда дойдём». Такое решение
не должно потеряться: оно записывается в реестр `docs/deferred/deferred.json`,
и хуки напоминают о нём, когда работа доходит до его темы.

## Как работают напоминания
- Хук **UserPromptSubmit** (`scripts/deferred.py hook-prompt`) ищет в каждом сообщении
  автора ключевые слова открытых решений и, если нашёл, добавляет в контекст НАПОМИНАНИЕ.
- Хук **SessionStart** (`scripts/deferred.py hook-session`) в начале сессии перечисляет
  открытые решения.
- Хуки читают настройки при старте сессии: новые хуки работают с первой сессии после
  слияния ветки, в которой они появились.
- Страховка на случай, если хуки не сработали (например, в чате, где репозиторий
  не стал проектом сессии): перед началом каждой логической страницы выполни
  `python3 scripts/deferred.py check --text "<тема страницы и ключевые понятия>"`.

## Получил НАПОМИНАНИЕ
1. До того как писать текст или код по теме — назови автору решение (id, вопрос),
   кратко предложи варианты с рекомендацией и спроси.
2. Если автор решил — закрой запись (см. ниже) и учти решение в работе.
3. Если автор снова откладывает — допиши в `context`, где возникло повторно, и при
   необходимости уточни `trigger`.
4. Если совпадение случайное (тема не та) — продолжай работу и сузь `keywords`.

## Добавить решение
Источник — раздел «Решения, откладываемые на будущее» логической страницы (docx) или
ответ автора «решим позже». Запись добавляется **при загрузке страницы в приложение**
(сессия загрузки), а если автор отложил решение прямо в чате — сразу.
```jsonc
{
  "id": "D005",                       // следующий свободный номер, D + три цифры
  "title": "Коротко, о чём решение",
  "raised_in": "21.v1-to-2.prompt",   // файл, где решение отложено
  "raised_on": "YYYY-MM-DD",
  "question": "Вопрос так, чтобы его можно было задать автору без контекста",
  "context": "Где возникло: страница, раздел; что уже известно, что не сверено",
  "trigger": {
    "keywords": ["основы слов по-русски", "Latin words"],  // латиница — целым словом
    "slices": ["rnn-1986"]            // id срезов, если уже известны
  },
  "status": "open", "resolution": "", "resolved_in": ""
}
```
- Ключевые слова выбирай так, чтобы они появились, когда работа дойдёт до темы:
  названия моделей и методов, русские основы («рекуррент», «диффузи»). Избегай слов,
  которые встречаются везде («нейросет», «ИИ»).
- После правки: `python3 scripts/deferred.py validate` (PostToolUse-хук делает это сам).

## Закрыть решение
`"status": "resolved"`, `"resolution"` — решение автора одной-двумя фразами,
`"resolved_in"` — файл или сессия, где оно принято. Записи не удаляются: реестр — это и
история решений. Если решение меняет схему содержания или архитектуру — нужен ещё и ADR.
