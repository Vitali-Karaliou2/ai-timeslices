# Создание демо (визуализации обучения)

## Правила (из CLAUDE.md, повторены, потому что здесь они критичны)
- Демо — самостоятельная статическая папка; оболочка показывает `entry` в iframe
  и ничего не знает об устройстве плеера.
- Демо проигрывает **заранее насчитанную трассу** (`trace.json`). Генератор трассы —
  Python-скрипт в `gen/`; он запускается при разработке, не при показе.
- Реализации NumPy и PyTorch одного демо дают **одну и ту же трассу** (одинаковый seed,
  одинаковый порядок примеров). Расхождение — баг или предмет отдельной страницы.
- Код генератора — это и есть «код для показа» на страницах `code-example`:
  один и тот же код, не два разных.

## Схема трассы (см. docs/spec/content-schema.md, раздел trace)
`trace.json`: `{ "meta": {...}, "points": [...], "steps": [...] }`
- `meta`: seed, библиотека, гиперпараметры, описание задачи;
- `points`: обучающие точки `{x, y, cls}` в порядке предъявления;
- `steps`: шаг на каждый обработанный пример:
  `{ "i": индекс точки, "params": {пар-ры модели после шага}, "loss": число }`.
  Для нейрона/персептрона на плоскости `params` достаточно для отрисовки
  разделяющих прямых (k, b или веса слоёв).

## Поведение плеера (единое для всех демо)
- До старта: все точки полупрозрачные, разделяющая линия в начальном положении.
- Пуск / пауза / шаг вперёд / сброс; ползунок скорости.
- На шаге i точка i становится непрозрачной, линия перерисовывается по `params`.
- Плеер — чистые HTML+canvas+JS без сборщиков и внешних библиотек; один общий
  `player.js` переиспользуется между демо, отличается только функция отрисовки модели.

## Шаги
1. Прочитай `docs/spec/content-schema.md` и одно существующее демо как образец.
2. Папка `content/slices/<slice-id>/demos/<demo-id>/`: `demo.json`, `index.html`,
   `player.js` (или ссылка на общий), `trace.json`, `gen/numpy/train.py`
   (и `gen/torch/train.py`, если требуется).
3. Сгенерируй трассу: `python3 gen/numpy/train.py > trace.json` (скрипт обязан печатать
   валидный trace и фиксировать seed).
4. Если есть обе реализации — сравни трассы автоматически (допускай расхождение только
   в пределах float-погрешности) и отрази результат в отчёте.
5. Проверка: `python3 scripts/validate_content.py demo.json`; открой страницу демо
   через оболочку (uvicorn) и убедись, что iframe загружается без ошибок в консоли.
6. В отчёте — гиперпараметры, seed, число шагов, размер trace.json (держи его < 1 МБ;
   если больше — прореживай шаги, записывая каждый n-й).
