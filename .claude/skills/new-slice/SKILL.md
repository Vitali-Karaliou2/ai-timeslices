# Создание нового тематического среза

Срез — единица содержания: отрезок истории ИИ с одной вводимой идеей (или связкой идей)
и последовательностью страниц. Этот скилл делает всё, что можно сделать до проверки
человеком, и явно оставляет человеку то, что делегировать нельзя.

## Входные данные (спроси, если не даны в задаче)
1. `id` среза (kebab-case), название, годы (точность 1–2 года).
2. Трек (`genai` | `xai`) и период (`golden` | `winter`).
3. Вводимая идея одной фразой; место среза в линейном порядке (после какого среза).
4. Какие демо нужны (из каталога абстрактных примеров в brief) и какие страницы.

## Шаги
1. Прочитай `docs/spec/content-schema.md` и один уже существующий срез как образец,
   чтобы не выдумывать поля.
2. Создай `content/slices/<id>/slice.json` со `status: "draft"` и упорядоченным списком
   страниц; добавь срез в `content/course.json` на согласованное место.
3. Страницы — `pages/<nn>-<page-id>.md` по типологии (overview / winter-overview / idea /
   math / library / code-example / demo / history / summary / questions / assignments).
   Обычный порядок внутри среза: idea → math → library → code-example → demo → summary,
   но он не догма — следуй материалу.
4. Для каждого демо — скилл `new-demo` (NumPy-реализация минимум; PyTorch — если срез
   уже после введения PyTorch).
5. Создай `questions.json`: не менее пяти вопросов, каждый с полным эталонным ответом,
   который обучаемый раскрывает сам. Без вариантов ответа.
6. Создай `assignments.json`: 2–4 задания-эксперимента, привязанных к демо среза
   (варьирование числа нейронов, слоёв, формы областей, learning rate и т. п.),
   с ожидаемым наблюдением («что вы должны увидеть»).
7. Прогони `python3 scripts/validate_content.py` для каждого созданного json.
8. Запусти субагента `fact-reviewer` на папке среза. Его замечания — в отчёт;
   не «исправляй даты» сам, если не уверен: помечай `ПРОВЕРИТЬ ДАТУ`.
9. Все тексты, которые увидит обучаемый, начинай с пометки `ЧЕРНОВИК:`.
10. Добавь срез в приёмочный тест линейного порядка (tests/test_course.py) —
    срез должен быть достижим и не ломать порядок.
11. В отчёте перечисли, что осталось человеку: (а) проверка дат и атрибуций,
    (б) утверждение текстов, (в) решение по месту среза в порядке, если оно спорно.
