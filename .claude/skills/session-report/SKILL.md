# Отчёт по итогам сессии

Отчёт — не пересказ действий, а то, что автору нужно, чтобы **проверить, не перечитывая
диалог**. Пиши его в конце ответа и дублируй в `docs/plans/<session>.md` под заголовком
`## Итог`.

## Разделы (строго в этом порядке)
1. **Сделано** — 3–7 пунктов, по результату, не по шагам.
2. **Сознательно не сделано и почему** — что из задачи отложено, какие ветви закрыты.
3. **Проверка** — какие команды запущены (`pytest`, `validate_content.py`, открытие
   страниц через uvicorn, генерация трасс) и результат. Если что-то не запускалось —
   так и напиши.
4. **Допущения, принятые за автора** — каждое отдельной строкой; все `ПРОВЕРИТЬ ДАТУ`.
5. **Черновик ADR** (если принималось решение, влияющее на схему содержания, схему БД,
   архитектуру или формат трасс): файл `docs/decisions/NNNN-<kebab-title>.md` по шаблону
   ниже. Создай файл со статусом `proposed`; на `accepted` меняет автор.
6. **Следующая сессия** — одна-три строки: с чего начать.

## Шаблон ADR
```
# NNNN. Название
Дата: YYYY-MM-DD. Статус: proposed | accepted | superseded by NNNN.
## Контекст
## Решение
## Последствия (включая то, что стало труднее)
## Альтернативы, которые отвергнуты, и почему
```
